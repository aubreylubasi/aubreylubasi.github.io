# aubreylubasi.github.io

My portfolio site: who I am, what I've built and how to reach me.

Live at **https://aubreylubasi.dev**

It's a single `index.html` with no build step. The fingerprint box at the top uses the browser's built-in Web Crypto API to compute a SHA-256 hash as you type, showing how one small change produces a completely different fingerprint.

To change the content, edit `index.html` and push. GitHub Pages updates the site within a minute or two.

## Pages

- `index.html`: the portfolio
- `privacy.html` and `terms.html`: privacy policy and terms for this site and my free apps (ZSL Translator, LubaVoice AI)
- `mineready/`: the MineReady landing page with its own privacy policy and terms
